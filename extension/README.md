# 指纹浏览器工作台 · 浏览器插件

Chrome/Edge (MV3) 伴侣插件：一键连接工作台、环境启停、右键"在指纹环境中打开"。

## 功能

- **一键配置**：默认地址开箱即连；认证开启时用**配对码**自动换取密钥（无需手动复制长 Key）
- **环境面板**：启停环境、查看内核/健康分/运行状态（5 秒自动刷新）
- **在环境中打开当前页**：把当前标签页发送到任意指纹环境（新环境以该页为起始页启动，运行中的 camoufox 环境直接导航）
- **右键菜单**：任意网页/链接上右键 →「在指纹环境中打开」→ 选择环境（环境列表自动同步）
- **自检快捷入口**：CreepJS / BrowserLeaks / Pixelscan 一键打开

## 安装（加载未打包）

1. Chrome/Edge 打开 `chrome://extensions`
2. 右上角开启 **开发者模式**
3. 点击 **加载已解压的扩展程序** → 选择本 `extension` 目录
4. 工具栏出现"指纹浏览器工作台"图标即安装成功

也可直接拖入打包好的 `fpworkbench-extension.zip`（解压后按上述加载）。

## 首次配置（一键）

| 场景 | 步骤 |
|---|---|
| 工作台未开启认证 | 点击插件 → **⚡ 一键连接** → 完成 |
| 工作台开启认证 | 工作台「系统设置 → 🔗 生成插件配对码」→ 插件中输入 6 位配对码 → **配对并连接** |

配对码 5 分钟有效、一次性、防暴力（最多 5 次尝试），全程审计留痕。

## 连接远程工作台

插件默认只允许访问本机（`127.0.0.1`/`localhost`）。连接局域网/远程工作台时，
编辑 `manifest.json` 的 `host_permissions` 加入目标地址（如 `"http://192.168.1.10/*"`），
在 `chrome://extensions` 重新加载插件，然后在插件设置中填写该地址。

## 目录结构

```
extension/
├── manifest.json          # MV3 清单
├── background.js          # Service Worker：右键菜单 + 环境同步
├── popup/                 # 弹窗（一键配置 / 环境面板 / 当前页发送）
├── options/               # 设置页（地址 / API Key / 测试连接）
└── icons/                 # 图标（由 scripts/make_icons.py 生成）
```

## 安全说明

- 密钥仅保存在浏览器本地 `chrome.storage.local`，不上传任何第三方
- 插件请求只发向你配置的工作台地址；右键菜单环境列表每 10 分钟同步一次
- 工作台默认监听 `127.0.0.1`，外网暴露请开启 API Key 认证并使用 HTTPS 反代
